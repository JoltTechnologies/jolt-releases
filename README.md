# JoltCLI public releases

This repository distributes standalone JoltCLI binaries for Linux, macOS and
Windows (AMD64 and ARM64). JoltCLI securely connects a development machine to
JoltCode by Threshold Labs.

Installation instructions and availability: https://joltcode.pages.dev/download

Each release includes a signed manifest, SHA-256 checksums, versioned installers
and uninstallers. Beta releases are explicitly marked as prereleases. The `beta/`
and `stable/` directories contain their respective signed update-channel pointers.

Application source code and signing credentials are not hosted here. GitHub's
automatically generated source archives contain only this distribution repository.
